# Python Practice Programs 🐍

This repository contains a collection of Python practice programs developed to strengthen my understanding of Python programming fundamentals and Object-Oriented Programming (OOP).

The exercises cover practical examples such as employee salary calculations, book borrowing systems, shopping carts, food ordering, library management, file handling, geometric calculations, and bank account operations.

## 📚 Topics Covered

- **Classes and Objects** – Creating classes, constructors, attributes, and methods.
- **Encapsulation** – Managing data using private attributes.
- **Inheritance** – Reusing and extending classes.
- **Polymorphism and Method Overriding** – Implementing customized class behavior.
- **Nested Classes** – Representing a car and its engine.
- **File Handling** – Reading from and writing to text files.
- **Conditional Statements and Loops** – Managing program logic.
- **Lists and Tuples** – Storing and manipulating collections of data.
- **Calculations and Business Logic** – Salary increases, discounts, totals, deposits, and withdrawals.

## 🚀 Programs Included

1. **Employee Class** – Calculate a 10% salary increase.
2. **Book Borrowing System** – Borrow, return, and display book availability.
3. **Shopping Cart** – Add and remove items and calculate the total price.
4. **Food Ordering System** – Manage food items, combo meals, discounts, coupons, and customer order history.
5. **Library Management System** – Manage books, users, borrowing limits, and book availability.
6. **Car and Engine System** – Demonstrate nested classes and engine start/stop functionality.
7. **File Handling** – Read, write, and display text file contents.
8. **Library Management Using OOP** – Practice inheritance, encapsulation, and book borrowing and returning.
9. **Rectangle Calculator** – Calculate area and perimeter and check whether a rectangle is a square.
10. **Bank Account System** – Perform deposits, withdrawals, and balance checks.

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming
- Built-in Python modules and data structures

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

3. Open the project folder.
4. Run the Python file:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the name of your Python script.
